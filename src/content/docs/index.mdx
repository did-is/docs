## Try it now

One request, no account. The response carries a plain-language verdict and seven evidence dimensions.

<Tabs syncKey="lang">
  <TabItem label="curl">
```bash
curl https://did.is/api/v1/resolve/did:web:did.is
```
  </TabItem>
  <TabItem label="TypeScript">
```ts
import { DidisClient } from "@didis/client";

const didis = new DidisClient();
const r = await didis.resolve("did:web:did.is");
console.log(r.verdict.headline);
for (const d of r.dimensions) console.log(d.id, d.state);
```
  </TabItem>
  <TabItem label="Python">
```python
from didis import DidisClient

with DidisClient() as didis:
    r = didis.resolve("did:web:did.is")
    print(r["verdict"]["headline"])
    for d in r["dimensions"]:
        print(d["id"], d["state"])
```
  </TabItem>
  <TabItem label="Rust">
```rust
#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let r: serde_json::Value = reqwest::get("https://did.is/api/v1/resolve/did%3Aweb%3Adid.is")
        .await?
        .error_for_status()?
        .json()
        .await?;
    println!("{}", r["verdict"]["headline"]);
    for d in r["dimensions"].as_array().into_iter().flatten() {
        println!("{} {}", d["id"], d["state"]);
    }
    Ok(())
}
```
  </TabItem>

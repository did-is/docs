Base URL `https://did.is/api`. No authentication. This page is generated from the [OpenAPI document](https://did.is/api/openapi.json); use that file for code generation.

Budgets: *standard* 20 requests per minute, *intensive* 2 requests per minute, per client. Every error is an RFC 9457 problem; see [Errors and rate limits](/build/errors/).

Every budgeted operation can answer `429 RATE_LIMITED` and `503 CAPACITY_EXHAUSTED`. Both carry a `Retry-After` header with the number of seconds to wait; read it on each response instead of using a fixed delay. Request bodies are limited to 512 KiB (`413 PAYLOAD_TOO_LARGE`).

### W3C DID Resolution (CR Draft)

```http
GET /1.0/identifiers/{did}
```

DID Resolution v1 · W3C Candidate Recommendation Draft (1 Oct 2026) HTTPS binding. Accept: application/did-resolution returns the full resolution result; application/did (or */*) returns the DID document only. Errors are RFC 9457 problem objects in didResolutionMetadata.error with the specification's status codes (400 invalid DID, 404 not found, 406 representation not supported, 410 deactivated, 501 method not supported). DID URLs (fragments, ?service=, ?versionId=) are dereferenced.

Budget: **standard**.

| Parameter | In | Description |
| --- | --- | --- |
| `did` (required) | path | Raw or fully percent-encoded (did%3A…); decoded exactly once. |
| `Accept` | header | application/did-resolution \| application/did |

Responses: `200`, `400`, `404`, `406`, `410`, `429`, `501`, `503`.

## Credentials and policies

### Verify a credential

```http
POST /v1/credentials/verify
```

Data Integrity (eddsa-jcs-2022, ecdsa-jcs-2019), VC-JWT 1.1 and vc+jwt. The signing key must belong to the issuer DID and be authorised for assertionMethod. Bitstring Status List entries are fetched, their list credential verified, and evaluated fail-closed. Status precedence: MALFORMED > INVALID > UNSUPPORTED > REVOKED > SUSPENDED > EXPIRED > NOT_YET_VALID > INDETERMINATE > VALID.

Budget: **intensive**.

Request body (JSON):

| Field | Type | Description |
| --- | --- | --- |
| `credential` (required) | object | Credential object, raw JSON string, or compact JWT. Raw text preserves member identity. |
| `expectedAudience` | string | Optional expected JWT recipient. Without it, audience is explicitly not verified. |

Responses: `200`, `400`, `413`, `429`, `503`.
